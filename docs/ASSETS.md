## GitHub 구성

코드·논문 설명·실험 설정·원시 결과표·집계 코드·그림 원본은 저장소에서 연결합니다. 모델과 데이터는 확보 가능한 다운로드 위치, 정확한 버전/파일명, 설치 위치와 checksum을 안내해야 합니다.

`local_materials`에는 얼굴 이미지·영상·연구일지·공유받은 자료가 포함되어 있습니다. 현재는 개인 연구 보관용으로만 복사했고 `.gitignore`에서 제외했습니다. 외부 전달할 데이터와 예시는 실제 출처·사용 조건을 확인한 항목으로 구성해야 합니다. 아직 GitHub에 업로드하거나 공유하지 않았습니다.

## 휴대 가능한 전체 보관본이 필요할 때

`tools/copy_external_assets.py`는 목록에만 등록된 원본을 지정 폴더로 복사합니다. 먼저 예상 용량만 확인하며 `--copy`를 붙여야 실제 복사합니다. 가상환경·Ollama 및 Hugging Face 캐시는 이 목록에 포함되지 않아, 이것만으로 실행 환경 전체 백업이 되지는 않습니다.
