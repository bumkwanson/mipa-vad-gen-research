# 실험·결과 자료

## 확보한 근거의 수준

| 항목 | 확보 상태 | 해석 |
|---|---|---|
| 영상→SRT·자막 영상 | 기존 파일 및 저장 완료 로그 존재 | 당시 실행 사례. 이번 재실행 검증은 아님 |
| POSTER 처리 약 59ms 등 | 공유 대화에서 관찰 | 원시 로그·정확한 코드 버전 미확보. 최종 결과표에 사용 보류 |
| RAVDESS 비교 | 실험 스크립트·Actor_01 파일 존재 | 최종 숫자·혼동행렬 로그는 미확보 |
| 발화/침묵 비교 | 실험 스크립트 존재 | 모델 간 일치율. 결과 파일은 미확보 |
| 사용자/전문가 평가 | 이번 수집에서 미발견 | 수행했다고 쓰지 않음 |

## 보완할 실험 설계 (제안, 미실시)

- 같은 클립 목록에서 대사만, 원시 비언어 라벨, 변화 기반 해설을 비교합니다.
- 해설 평가: 영상 사실과의 일치, 잘못 추가된 묘사, 비언어 정보 포함, 중복 설명, 발화와의 겹침, 읽기 부담을 분리합니다. 평가자 수·평가 기준·익명화된 평가표를 보관합니다.
- 표정 평가: 클립/인물 단위 분할, 클래스 분포, accuracy·macro-F1·혼동행렬, 미검출률을 기록합니다. 한 배우의 결과를 전체 인물에 일반화하지 않습니다.
- 발화/침묵 비교: 기준 모델 버전, 유효 프레임 마스크, 시간 동기, 표본 수를 남깁니다. 인접 프레임을 독립 표본으로 간주한 유의성 주장을 피하고 인물/클립 단위 차이도 보고합니다.
- 성능: 워밍업 조건, 입력 길이·fps·해상도, 모델 로드 시간과 처리 시간, LLM 생성 시간, 전체 소요 시간을 별도로 저장합니다.
- 설정 고정: 코드 SHA-256, 가중치 hash, 데이터 식별자, 프롬프트, temperature·seed(지원 시), 라이브러리와 하드웨어를 함께 저장합니다.

## CSV 결과 표 헤더

`result_template.csv`는 헤더만 있는 양식입니다. 실제 결과 행은 아직 없습니다.

| 결과에 반드시 포함 | 목적 |
|---|---|
| run_id, timestamp, code_hash | 실행과 코드 연결 |
| dataset, clip_id, participant_id | 입력과 평가 단위 식별 |
| split, condition, reference_type | 비교 조건·정답 출처 구분 |
| total_units, evaluated_units, failed_units | 분모·누락 공개 |
| metric, value, unit | 숫자의 의미 |
| config_path, raw_log_path | 재현 근거 |

## 논문 표에 넣기 전

원시 예측 → 집계 스크립트 → 결과 CSV → 표/그림의 연결이 있어야 합니다. 타 모델 논문의 성능 숫자, Claude의 해석, 코드 주석의 “검증 완료”를 본 연구의 측정 결과로 대체하지 않습니다.
