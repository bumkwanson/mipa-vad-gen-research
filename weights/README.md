# POSTER++ 가중치

`python scripts/download_weights.py`를 실행하면 아래 파일을 이 폴더에 받습니다.

```text
weights/
├── raf-db-model_best.pth
└── pretrain/
    ├── ir50.pth
    └── mobilefacenet_model_best.pth.tar
```

자동 다운로드가 실패하면 POSTER++ 공식 저장소가 제공하는 Google Drive 링크에서 직접 내려받으세요.

- [RAF-DB checkpoint](https://drive.google.com/file/d/1aVm_hmJyZ5E_0p25XTbm3X9ophsKqCxv/view?usp=sharing) → `raf-db-model_best.pth`
- [IR-50 pretrained model](https://drive.google.com/file/d/17QAIPlpZUwkQzOTNiu-gUFLTqAxS-qHt/view?usp=sharing) → `pretrain/ir50.pth`
- [MobileFaceNet pretrained model](https://drive.google.com/file/d/1SMYP5NDkmDE3eLlciN7Z4px-bvFEuHEX/view?usp=sharing) → `pretrain/mobilefacenet_model_best.pth.tar`
